# 壁画裂隙矩形贴片精确加固

潮湿壁画上的裂隙常呈 **孔洞、细枝和孤岛**。保护员需要用 **不可重叠的矩形纤维贴片**
覆盖全部裂格，且不能压住任何完好格。局部贪心（哪里大贴哪里）常常多耗贴片；
本项目在浏览器内自行实现 **精确状态空间搜索**，给出贴片数最少的唯一可复算方案。

纯前端应用：TypeScript + React + Vite，**无业务后端、无任何外部在线调用**，
所有计算在浏览器本地（搜索在 Web Worker 中执行，不阻塞界面）。

## 业务规则

- 网格大小：`1×1` 至 `12×12`，可点击单元格切换「裂格 / 完好格」，裂格最多 60 个。
- 合法贴片：
  - 边沿格线放置（轴对齐整数矩形）；
  - 贴片内 **只含裂格**，不得压住完好格；
  - 贴片之间 **不得重叠**；
  - 所有贴片的 **并集恰为全部裂格**（不多不少）。
- 优化目标（唯一主目标）：**贴片数量最少**。
- 并列决胜：把每个矩形记为一个基坐标的四元整数
  `[上, 左, 下, 右]`（行列均自 0 起，含边界），
  各方案内部先按该四元组字典序排序，再把所有矩形依次拼接成整数序列，
  **取字典序最小的方案**。因此对任一合法输入，最终只会呈现唯一一个可复算的加固方案。

## 界面功能

- SVG 网格：点击切换裂格；深色为裂格，彩色圆角块为最终贴片。
- 结果面板：最优贴片数、搜索状态数、耗时、局部贪心对照（贪心多耗几块一目了然）。
- 每块贴片的 `上/左/下/右` 坐标列表。
- **分支取舍回放**：记录搜索中的「采用分支 / 下界剪枝 / 放置后超限回溯 /
  同态记忆剪枝 / 得到完整方案 / 贪心初始上界」等事件，可用按钮或滑块逐步查看，
  图上同步高亮当前候选矩形与锚点格。
- 明确错误反馈：尺寸非整数、超出 1–12、裂格超过 60、越界等情况都会给出原因；
  **任何越界/非法输入都会立即清除旧解**，避免把过期方案当作当前答案。
- 内置四个预设：孔洞（3×3 环）、狭枝（十字）、并列决胜（L 形三格的横/竖并列，
  字典序取横铺）、贪心反例（精确最优 2 块、局部贪心 3 块）。

## 搜索算法（完备且可复算）

实现在 `src/lib/solver.ts`：

1. **确定性锚点**：每一步选行优先序下第一个未覆盖裂格。
2. **完备候选枚举**：枚举「锚点列连续自由行带 × 行带内包含锚点列的左右界」
   生成的每一个只含自由裂格的矩形。任何合法铺法中覆盖锚点的那块矩形必在其中，
   因此搜索朴素完备（不依赖“极大矩形不劣”之类的可争辩剪枝）。
3. **初始上界**：先以同一锚点规则跑一遍「每步取面积最大候选」的贪心解。
4. **下界剪枝**：在剩余裂格中构造一个“任意两格都不可能被同一矩形覆盖”的格集
   （两格可同矩形覆盖 ⇔ 其包围盒内当前全为自由裂格），其大小是贴片数的合法下界，
   不弱于四邻接连通分量下界。
5. **同态记忆**：同一剩余覆盖形态若曾以严格更少的贴片数到达，则当前路径必不更优。
6. **字典序决胜**：叶节点比较展平整数序列，全局保留最小者。

另在 `src/lib/bruteforce.ts` 提供一个 **刻意不同实现** 的独立慢速穷举器
（枚举全部合法子矩形 + MRV 精确覆盖回溯），仅用于验收交叉验证。

## 本地开发

```bash
npm install
npm run dev        # 开发服务器 http://localhost:5173
npm run build      # 类型检查 + 生产构建（输出到 dist/）
npm run preview    # 本地预览生产构建
```

## 测试

```bash
npm run typecheck  # 仅 TypeScript 类型检查
npm run test       # Vitest：单元测试 + 全部 65536 个 4×4 图样穷举交叉验证
npm run e2e        # Playwright：真实 Chromium 交互测试（自动 build + preview）
npm run verify     # 一键：typecheck + vitest + playwright
```

- **Vitest**（`tests/`）
  - `rect.test.ts`：坐标、排序、字典序、铺法合法性（重叠/压完好格/遗漏/越界）。
  - `validation.test.ts`：全部非法输入类别与错误文案。
  - `solver.test.ts`：孔洞、狭枝、孤岛、并列决胜（L 形横/竖铺法）、
    确定性与插入顺序无关、分支轨迹、12×12/60 裂格性能。
  - `exhaustive4x4.test.ts`：**独立慢速穷举器对全部 2¹⁶ = 65536 个 4×4 图样**
    逐一核对最优贴片数与字典序决胜方案，并断言孔洞类、狭枝（走廊）类与并列类
    图样均被实际覆盖。
- **Playwright**（`e2e/app.spec.ts`，真实浏览器）
  - 点击切换裂格与计数、应用 12×12、非法尺寸与非整数的错误反馈及旧解清除、
    60 裂格上限、三个预设的搜索结果、SVG 贴片渲染、分支回放逐步联动、
    同一图样两次搜索结果逐字一致。

## Docker 发布与验收

```bash
# 发布（默认宿主端口 8080）
docker compose up --build web
# → http://localhost:8080

# 用 WEB_PORT 覆盖宿主端口
WEB_PORT=9000 docker compose up --build web

# 一次性验收服务（类型检查 + Vitest 穷举验收 + Playwright 真实交互，跑完即退出）
docker compose build verify
docker compose run --rm verify
```

- `web`：多阶段构建，最终镜像仅为 nginx + 静态产物（`dist/`），
  宿主端口 `${WEB_PORT:-8080}` 映射到容器 80。
- `verify`：基于 Playwright 官方镜像（浏览器预装）的一次性服务，
  `restart: "no"`，退出码即验收结论。

## 目录结构

```
src/
  lib/
    rect.ts         # 矩形模型、字典序工具、铺法合法性校验
    solver.ts       # 精确状态空间搜索（主算法 + 分支轨迹）
    bruteforce.ts   # 独立慢速穷举器（仅验收用）
    validation.ts   # 尺寸/裂格校验与明确错误信息
  workers/
    searchWorker.ts # Web Worker 包装
  App.tsx           # React 界面（SVG 网格、结果、分支回放）
tests/              # Vitest（含 65536 图样穷举验收）
e2e/                # Playwright 真实交互测试
docker/             # nginx 配置
Dockerfile          # deps / build / verify / web 多阶段
docker-compose.yml  # web（WEB_PORT 覆盖）+ 一次性 verify
```
